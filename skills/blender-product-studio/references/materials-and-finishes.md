# 材质、表面工艺与实拍校准

在新建材质、跨产品复用材质或排查“不像摄影”时读取。只调已接受场景的一盏灯，不必重新做整套材质验收。

## 先确定可见表面，而不是只问材料名称

为关键部件记录：基材、表面处理、涂层/印刷层、颜色依据、纹理方向、真实尺度、厚度及证据可信度。普通照片不能唯一反求粗糙度、IOR 或涂层结构；给未知项保留可调参数，不从外观断言塑料牌号、合金或制造公差。

| 表面 | 重要判断 | 常见错误 |
| --- | --- | --- |
| 哑光/注塑塑料 | 非金属反射、表面微结构、分模线与局部厚度 | 把所有塑料做成同一粗糙度，或用粗噪声冒充磨砂 |
| 亮面塑料 | 清晰但受曲率控制的反射，是否确有涂层 | 为了“塑料感”给每件都加厚清漆或大面积油光 |
| 半透明塑料/树脂 | 透射、散射、厚度共同决定表现 | 用降低 Alpha 代替实体透光；未确认材质就强加次表面散射 |
| 软触塑料/橡胶 | 哑光、柔和反射与真实表面纹理 | 认为“软”必须靠大范围次表面散射；把硅胶参数通用于所有软触涂层 |
| 裸露镜面金属 | 金属反射色、曲率、周围明暗反射带 | 因反射黑环境而发黑时盲目加曝光/漫反射 |
| 拉丝/车削金属 | 方向性反射、UV/切线方向与微纹理一致 | 只画条纹；圆柱环向拉丝却配置成纵向高光 |
| 喷砂金属 | 较宽反射、细微表面起伏 | 把喷砂做成石头或完全无反射的灰色 |
| 喷漆/电镀/阳极氧化 | 依实际可见层区分；不透明漆、金属镀层和透明氧化层不同 | 只因内部是金属就把外面不透明漆 Metallic 设为 1；反过来又把所有涂层当普通塑料 |
| 玻璃/液体 | 闭合厚度、界面、吸收与透射路径 | 染暗标签代替玻璃颜色；玻璃和液体重叠面产生假黑边 |
| 纸/覆膜/烫金 | 纸纤维、膜反射、墨与工艺遮罩分别控制 | 整张纸设成金属；把印刷阴影烘死进底色 |
| 布料/皮革/木石等 | 有明确参照时用适配 PBR 或扫描素材，并核对纹理尺度和许可 | 仅改颜色便宣称为某种真实材料；把摄影贴图里的光影再照一遍 |

清漆可以盖在金属或非金属上；不透明漆覆盖时，可见表面以介电层为主。金属/介电间的灰度混合可用于边界、污层或混合表面，但不是任意“增加质感”的旋钮。对薄膜干涉、珠光、多层特种涂层，先看实物随角度变化的证据，再决定专用节点/层结构，不强行套基础预设。

## 微结构和贴图

颜色、粗糙度、法线/高度、工艺遮罩职责分开。颜色图使用其正确颜色空间，数据图按数据读取。先确认供应商的法线方向约定和单位，不默认所有 normal map 方向相同。

纹理以毫米或微米级尺度校核，在实物比例和最终像素尺寸下判断。仅影响高光的小纹理优先粗糙度/法线；影响轮廓、接缝、压印或近景阴影的结构才用几何/置换。考虑相机距离和输出，防止细纹闪烁、摩尔纹与降噪抹平。

新产品不默认添加灰尘、划痕和指纹。需要自然细节时使用低强度、有制造或使用逻辑的变化；广告允许的凝露/磨损放在可关闭的变体层，不烘入唯一主材质。

## 中性验证与广告验证分开

1. 用真实尺寸和正确 UV 的产品或代表性部件，固定相机、灯、背景、视图变换、曝光和白平衡。
2. 分别看整体颜色、反射带形状/宽度、掠射角、透光和表面特写。同一高光变宽可能来自光源尺寸或粗糙度，比较时不要同时改变两者。
3. 实拍条件尽量可比；不同手机滤镜、未知曝光和印刷色不能被当成精确测量。严格色彩匹配另需受控照明/色卡和显示流程。
4. 在实际产品形状与目标广告机位上再检查一次：材质球通过不等于瓶肩、平盒面和倒角都通过。
5. 保存材质参数、参照、尺度和预览。分别标记“示例起点”“渲染检查通过”“实拍匹配”“用户接受”，不把脚本通过写成材质已校准。

材质有明显变化时做小范围验收；只改输出尺寸不强制重做。镜面、半透明和复杂层材质至少核对一个不同视角或光照方向，避免只在一个机位成立。

## 随附可执行起点

`assets/material-presets.json` 是有明确单位的艺术起点，不是测量数据库。包含塑料、裸金属、不透明喷漆、玻璃、纸与示例金箔；需要实物校准。软件中能正确渲染，不代表准确复制某个 PP/ABS、金属或品牌色。

在新的后台进程创建材质测试棚（不可带产品 `.blend` 输入）：

```bash
blender --background --factory-startup --python-exit-code 1 --python "$SKILL_DIR/scripts/build_material_lab.py" -- --output "$OUT/material-lab.blend" --rig neutral
```

`--rig` 可选 `neutral`（宽面中性）、`surface`（条状反射/表面层次）、`glass`（后侧轮廓与较弱正面补光）。`--presets plastic_matte,plastic_gloss,metal_brushed,metal_polished` 可以只选指定样板。脚本不渲染、不打开/覆盖任何产品文件；输出已存在时拒绝覆盖。随后用 `render_still.py` 渲染指定预览。

生成文件有可编辑材质和独立 `BPS_Rig_*` 集合，材质标记为资产。样板几何并非用户产品。起点函数也可导入自己的制作脚本：

```python
import sys
sys.path.insert(0, str(skill_dir / 'scripts'))
from build_material_lab import load_presets, create_material, create_light_rig
presets = load_presets()
new_mat = create_material('metal_brushed', presets['metal_brushed'], meters_per_unit=scene.unit_settings.scale_length)
rig = create_light_rig(scene, 'surface', target=(0, 0, 0.05), span_m=0.20)
```

函数只创建新数据，不给现有产品赋材质、不删除原灯光、不自动保存。引用材质时由调用者明确选择部件/变体；不要改写整个主资产。灯组与现有灯同时存在时总照度会变；在本地场景副本内决定哪些组启用。不要在链接库内部新增摄影灯。

程序纹理使用对象局部坐标，假定几何单位与 `meters_per_unit` 相符且物体缩放为 1。非均匀缩放会改变纹理，需要在副本上处理坐标，不随意 Apply 用户主资产。拉丝使用活动 UV 的切线；模型缺 UV 或需要不同刷纹方向时先解决映射。玻璃示例使用厚壁杯形样板与薄板，产品仍需自己的真实厚度。
