# 广告摄影、验收与分层交付

在广告主视觉、系列投放或需要后期精修时读取。普通模型预览/单张 PNG 不强制增加 EXR、场景或审批步骤。

## 拍摄目的与不变量

从用户现有参考提取主体、视觉重心、留白、景别、氛围和允许的道具；未明确时作可逆的小样，不把可选方案变成必须三稿。记录这张图要表现的产品特点：材质、结构、容量/系列、使用方式或包装，而非只添加灯和道具。

先明确本次必须保持的内容：真实比例、产品数量、Logo/文案、包装结构、盖子状态和关键颜色。广告化的悬浮、水滴、液流、颜色强化与实物资料图分开。不要为了参考图中的夸张效果悄悄拉伸产品、改标签或隐藏关键结构。

涉及留白/文案时记录安全区和交付画幅。竖图、方图、横图必要时分别安排机位/摆位，不能保证对所有画幅简单裁切。指定参考优先，不附加用户明确排除的道具、文字或特效。

## 可比较的迭代

有参考时按摄影指南的外轮廓、顶/侧面、透视与间距对照。比较材质时固定相机和灯；比较灯时固定材质/曝光基准；比较机位时保持光组和产品比例。每个方案记录版本与实际文件，用户确定后继续，不重新随机生成方向。

产品检验与广告审美分别验收：

- 几何：轮廓、倒角、接缝、盖口、接触、穿模和真实尺寸；主资产与场景变体身份清晰。
- 材质：整体/掠射角/特写是否可信，光泽和纹理尺度是否吻合参照；金属不靠乱加划痕，塑料不靠大颗粒噪声。
- 摄影：高光不遮重要标签、亮部不过度丢信息、黑部仍有目标所需层次，接触阴影与落地一致。
- 广告：主体卖点明确、品牌字可读、道具不过度竞争、留白和裁切可用。
- 输出：实际像素与有效细节、前后清晰度、透明边缘、色彩转换和完整依赖；明确哪个状态已接受。

常规需要整体预览加关键区域 100% 像素检查；预览放大不能证明高清细纹合格。先调纹理/采样/降噪来源，再考虑锐化；不得把过度锐化或低清放大当真实细节。

## 颜色管理

材质比较记录相同的灯光颜色、曝光、白平衡、视图变换和 Look。图像底色是 sRGB 还是线性数据需要明确，粗糙度/遮罩/法线不可误作颜色。

AgX、Khronos PBR Neutral 等视图变换按用途和当前 Blender 支持选择，不把任何一种当所有产品的唯一正确答案。PBR Neutral 适合受控中性光的颜色保真目标，但不能自动保证品牌色与印刷色一致；AgX 的高光压缩也不等于应随意改材质补色。

成片 PNG 通常是已应用显示变换的交付图；原始 EXR 是场景线性数据，需要下游使用匹配的 OCIO/视图变换。记录两者区别，避免后期重复应用变换。印刷交付需要约定 ICC/印前流程，不宣称 RGB 数值等于最终印刷色。

## 分层输出的选择

先问用途或沿用既定交付；不要默认所有小样输出几十个通道。

| 需求 | 输出及注意事项 |
| --- | --- |
| 直接使用 | 合成完成的 PNG/JPEG（透明需 PNG），附像素/颜色说明 |
| 换背景/保留落地 | RGBA 产品及需要的阴影层；玻璃仍会反射/折射原环境，Alpha 不能保证任意背景都正确 |
| 局部精修 | 多层 EXR 的对象/材质 Cryptomatte、必要反射/透射等通道；下游软件需支持 |
| 调主补光比例 | Light Groups；可以调整既有光照贡献的颜色/强度，不能在后期改变光源位置、尺寸、阴影形状或光学结构 |

Cryptomatte 能生成对象/材质遮罩，但不是把玻璃后的所有物体自动独立、完整地恢复成可替换层。需要精确换背景/换折射时，用目标背景重渲或专门分层方案。单独阴影层也需要实际的 catcher/视图层设计，不因打开通道就宣称已做好。

保留未经破坏的主合成图与原始 EXR。高光柔化、局部对比、轻量色调修饰属于摄影后期；不能悄悄改产品结构、文字、瓶数。用户要求后续 AI 添景时，把产品区域保护和不能修改的品牌信息作为交付约束；不将 AI 改写后的产品称作准确的 Blender 渲染。

灯组通常应在线性空间合并后再统一显示变换。Combined 与各通道的降噪状态可能不同，不能保证降噪成片等于单独处理后的灯组简单相加；检查残余噪点和合成一致性，尤其是金属高光、玻璃和低照度区域。

## 辅助脚本边界

多层 EXR 的调用见渲染与交付指南。随附工具只输出原始 Cycles view layers/passes，不生成 PSD、不自动建立阴影层、不保留合成器最终调色在原始 EXR 中，也不把所有发光网格自动分组。需要这些效果时另建明确的版本化合成流程。

参考：[Blender Passes / Cryptomatte / Light Groups](https://docs.blender.org/manual/en/latest/render/layers/passes.html)、[颜色管理](https://docs.blender.org/manual/en/latest/render/color_management.html)。
