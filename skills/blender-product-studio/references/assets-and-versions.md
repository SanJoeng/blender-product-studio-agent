# 主资产、摄影场景与版本

## 三层分工

```text
项目/
├── 资料/                 实拍、原始刀模、标签、尺寸依据
├── 资产库/产品ID/        主资产.blend、派生贴图、结构说明
├── 素材库/               通用道具、HDRI、材质及来源许可
├── 场景库/场景ID/        链接实例、摄影机、光组、背景、场景变体
├── 输出/场景ID/版本/     预览、正式图、渲染记录
├── 历史版本/             可恢复快照
└── 项目索引.json          接受的产品/场景版本与输出对应
```

这是新项目可用的布局；已有项目保留现有组织，只补齐缺少的索引和连接。不要为套模板而批量移动素材使相对路径失效。

## 主资产的稳定接口

每个 SKU 有独立 `asset_id`、稳定发布路径和可链接集合名；尺寸、局部坐标、根控制器、开合属性是跨场景接口。语义名称优于把每次“最新版”追加进集合名。一个礼盒内的重复单瓶也链接单瓶主资产，避免盒内瓶与外部单瓶更新脱节。

需要反复调用的资产可登记到 Blender Asset Browser，附中性缩略图、产品类型、尺寸、修订与来源，方便搜索；缩略图不是正式摄影场景。

场景通过 `Linked Collection` 与本地实例控制器摆放产品。基础网格、UV、贴图与基础材质在主资产维护。透明背景、桌面、反光板、摄影机、灯和场景液流在场景维护。实例缩放一般保持 1；不可仅为参考图效果破坏产品间真实比例。

主资产更新流程：保存修改前快照 → 在候选文件做修改 → 核对尺寸/结构/UV → 按用户授权发布至稳定路径 → 重新打开或 reload 依赖场景 → 核对代表性场景。链接文件已读入的会话不会瞬间热更新，旧 PNG 也不会变化。区分“主资产已发布”“场景已重载”“哪些成片已重渲”。

场景里需要多个不同开合状态时，优先链接拆分部件并使用本地姿态控制，或使用稳定定义的展示集合。原始链接集合实例不保证各实例可以独立改内部属性。确有需要时采用针对姿态/材质的受控 Library Override，记录覆盖字段；不要把整套产品随意 Make Local。

## 变体的同步边界

用户要改全产品的实物结构，更新主资产；用户只要某张广告更深的玻璃、湿润表面或特殊包装姿态，建立场景变体并记录基础版本。

材质覆盖应有 `base_asset_revision` 和覆盖列表。若复制对象但保留链接 mesh，再本地覆盖材质，原 mesh 的几何更新可继续传播；新增/删除部件、对象变换、控制器和基础材质改变不一定自动传播。不得把这类变体称为“所有改动都自动同步”。更新主资产后需协调这些变体。

对没有变体机制的旧项目，不在每个场景分别补丁式改同一产品。先辨别产品主体、提取并发布主资产，再替换场景中的产品实例；保留原相机、摆位与光组。若存在用户局部手改，记录差异后迁移，不能以重建脚本覆盖它们。

## 当前版和回退

不凭修改时间或文件名中的“最终/最新/提亮”决定输入。索引至少记录：

- 产品：`asset_id`、主资产路径、集合名、尺寸依据、修订、依赖、场景变体。
- 场景：`scene_id`、修订、父版本、输入资产、产品姿态、相机/光组、预览路径、本次变化和接受状态。
- 当前工作版与已接受版：各自明确指向一个场景文件，不能混为一谈。
- 渲染：源场景/依赖版本、源场景哈希、相机、帧、尺寸、设置、输出、用时与设备。

有实拍校准与广告需求时，项目索引可另外记录 `capture_sets`（采集条件/覆盖/用途）、`material_checks`（部件/预设/证据/测试棚/接受状态）和 `shot_briefs`（卖点/不变量/留白/变体与输出）。空列表不代表已经完成这些工作；已有索引时添加必要字段，不强制迁移全部格式。

“改回玻璃刚加深那个”应定位那个版本及缩略图，切换当前工作指向；若用户后续又有希望保留的修正，重放明确保留的变化。打开已有旧文件、实际改动场景、重新渲染是不同动作，分别准确报告。避免只说“已恢复”却继续用另一个文件渲染。

建议版本名简短明确，如 `shot03_v005.blend`；变化写在索引中。保留历史文件、`.blend1` 和用户来源文件。已生成且确认可替换的本轮草稿可以更新，正式已交付文件默认另存新修订。

## 路径、依赖与移交

贴图可以打包入资产或放在资产附近用相对路径。打包图片不等于打包所有外链 `.blend`；嵌套库、UDIM、序列贴图、模拟缓存与 HDRI 都需要检查。路径修复先确定原图身份，不能把不同产品中同名的“正面.png”盲目互换。

下载道具或 HDRI 时记录来源、作者、许可和适用限制；用户素材的许可未知时记录未知，不宣称可随意再分发。下载与采用付费素材只在授权范围内进行。

项目移交需要新环境能解析依赖、重新载入资产和复现相机。有动画/模拟时确认缓存和帧范围。交付前从保存文件重新载入做必要的依赖检查，不能只相信当前会话里缓存着的图片。

若下游另需 GLB、FBX 或 USD，先确认用途再导出，并检查单位、轴向、层级和贴图。Cycles 的复杂玻璃、程序化纸张和体积材质不保证在其他渲染器中一致，必要时另做材质适配或烘焙；保留 `.blend` 作为可编辑源。
